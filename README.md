# Food Diary App

The Food Diary App is a simple application designed to help users track their daily meals and physical activity. Users can record their meals for each day along with the physical activities they engage in. The data is stored locally using SQLite, providing a convenient and secure way to manage personal information.

## Features

- **Meal Logging**: Users can log their meals for breakfast, lunch, dinner, and snacks for each day.
- **Activity Tracking**: Users can record their physical activities, such as workouts, walks, or any other exercises.
- **Local Storage**: All data is stored locally using SQLite, ensuring privacy and security.
- **Editing**: Users can easily edit their logged meals and physical activities.

## Getting Started

To use the Food Diary App, follow these steps:

1. **Install Dependencies**: Make sure you have Flutter installed on your system.
2. **Clone the Repository**: Clone or download the repository from [GitHub](https://github.com/yourusername/food-diary-app).
3. **Navigate to the Project Directory**: Open a terminal window and navigate to the directory where the project is located.
4. **Clean the Project**: Run the following command to clean the project:

   ```bash
   $ flutter clean
   ```

5. **Get Dependencies**: Run the following command to get the project dependencies:

   ```bash
   $ flutter pub get
   ```

6. **Run the App**: Execute the main application file to start using the app.

   ```bash
   $ flutter run
   ```

## Usage

1. **Logging Meals**:
    - Select the meal type (breakfast, lunch, dinner, or snack).
    - Enter the details of the meal, such as food items consumed and portion sizes.
    - Save the entry to record the meal.

2. **Recording Physical Activity**:
    - Choose the type of activity from the provided options.
    - Enter the duration and intensity of the activity.
    - Save the entry to record the activity.

3. **Editing Entries**:
    - Navigate to the day and entry you wish to edit.
    - Make the necessary changes to the meal or activity.
    - Save the edited entry.
